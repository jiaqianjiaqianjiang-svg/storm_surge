# 1997 Historical Typhoon Hindcast - Compact Results

- Events: Beihai ZITA and Lianyungang WINNIE.
- Three fixed 72-hour forecast origins per event.
- Historical hindcast with known future ERA5 forcing, not an operational forecast.
- Additional 1997 case analysis, not a new blind test.
- Raw ERA5, GESLA data and model checkpoints are not included.
